A small CSS override to allow you to set your own font across all of GitHub.

<img width="1263" height="641" alt="image" src="https://github.com/user-attachments/assets/a941542f-5e41-47a8-9f25-a210bf349164" />

The reason for making this was to be able to view [icons](https://github.com/nvim-mini/mini.icons) within repository code.

# Install

1. Install the [Refined GitHub](https://github.com/refined-github/refined-github) browser extension.

2. In the `Custom CSS` settings, paste the contents of [font.css](font.css).

3. Change the `github-font-override` variable to whichever font you would like.

I recommend a [Nerd Font](https://www.nerdfonts.com/) to view icons!
